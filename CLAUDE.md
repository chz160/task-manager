# CLAUDE.md

Standing rules for any AI agent working in this repository.

## No AI attribution, ever

Never attribute any work in this repository to Claude, AI, or agents. This applies to everything an agent writes or publishes, including:

- Commit messages: no `Co-Authored-By: Claude ...` trailer, no `Claude-Session: ...` trailer, no other trailer or line naming an AI, model, or agent.
- Commit authorship: commits are authored and committed as `Noah P. <chz160@yahoo.com>`. Never commit as Claude or any agent identity. Set it explicitly if the environment default differs, for example `git -c user.name="Noah P." -c user.email="chz160@yahoo.com" commit ...`.
- Pull request titles and descriptions: no "Generated with/by Claude Code" (or similar tool-attribution footer in any wording), no session links, no "written by AI" statements.
- PR comments, issue comments, review replies, and review bodies: no AI footers, signatures, or session links.
- Code comments, docs, changelogs, and release notes: no "generated by AI" notes.
- Branch names, tags, and file names that credit an AI or agent as the author (mentioning an AI product by name where it is the subject, such as this file, is fine).

If a tool, template, or default setting adds attribution automatically, remove it before committing or posting. If it cannot be removed, stop and tell Noah instead of committing as an agent.

## Correct and remove any attribution you find

If an agent finds AI attribution that already exists in the repository, in a PR, or in a comment, it must correct it:

- Files, docs, and code comments: remove the attribution in the current change.
- Open PR descriptions and comments: edit them to remove it.
- Unpushed or unmerged commits on your own branch: amend or rewrite the message and author.
- Already-merged history on `main`: do not rewrite it on your own. Rewriting history force-pushes `main` and closes open PRs. Report it to Noah and let Noah decide.

## Exception: the platform PR marker

Pull request bodies opened through the Claude Projects platform must start with a required marker (`<!-- claude-projects-attribution: ... -->`) and a `_Requested by **<name>** ..._` line. These are added by the platform, credit the human who requested the work, and must stay in place. They are not exempt from the rules above in any other way: do not add anything else.
